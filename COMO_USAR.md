# 🚀 COMO USAR O WHATSAPP AUTOMATION

## ▶️ BOTÃO EXECUTAR - GUIA SIMPLES

### 1️⃣ **EXECUTAR A APLICAÇÃO**

**Para Linux/Mac:**
```bash
./run_gui.sh
```

**Para Windows:**
```bash
run_gui.bat
```

**Ou execute diretamente:**
```bash
mvn clean compile
java -cp target/classes:target/dependency/* com.raphael.whatsapp.WhatsAppGUI
```

### 2️⃣ **USAR O BOTÃO EXECUTAR**

1. **Abra a aplicação** - Uma janela gráfica irá aparecer
2. **Clique no botão "▶️ EXECUTAR WHATSAPP AUTOMATION"**
3. **Aguarde** - O Chrome irá abrir automaticamente no WhatsApp Web
4. **Escaneie o QR Code** - Use seu celular para fazer login
5. **Pronto!** - Os outros botões ficarão habilitados

### 3️⃣ **FUNCIONALIDADES DISPONÍVEIS**

#### 🟢 **Após clicar EXECUTAR:**
- ✅ WhatsApp Web abre automaticamente
- ✅ Botões de envio ficam disponíveis
- ✅ Log em tempo real na tela

#### 📱 **Enviar Mensagem Simples:**
1. Digite o **nome do contato**
2. Digite a **mensagem** 
3. Clique **"📱 Enviar Mensagem"**

#### 🤖 **Bot Interativo:**
1. Clique **"🤖 Iniciar Bot Interativo"**
2. Use o **console** para comandos avançados

### 4️⃣ **DICAS IMPORTANTES**

- 🔴 **Mantenha o WhatsApp Web aberto** durante o uso
- 📱 **Não deslogue** do WhatsApp Web manualmente  
- ⚡ **Os nomes dos contatos** devem ser exatos (como aparecem no WhatsApp)
- 🔄 **Se der erro**, clique em EXECUTAR novamente

### 5️⃣ **RESOLUÇÃO DE PROBLEMAS**

**❌ Se o botão EXECUTAR der erro:**
1. Feche o Chrome completamente
2. Clique no botão **"❌ ERRO - CLIQUE PARA TENTAR NOVAMENTE"**
3. Se persistir, reinicie a aplicação

**📱 Se não encontrar o contato:**
- Verifique se o nome está **exatamente igual** ao WhatsApp
- Teste primeiro com um contato **recente**

### 6️⃣ **COMANDOS RÁPIDOS**

| Ação | Como fazer |
|------|------------|
| 🚀 **Iniciar** | Clique "EXECUTAR WHATSAPP AUTOMATION" |
| 📱 **Mensagem rápida** | Nome + Mensagem + "Enviar Mensagem" |
| 🤖 **Bot avançado** | "Iniciar Bot Interativo" |
| 🔄 **Reiniciar** | Feche e abra a aplicação |
